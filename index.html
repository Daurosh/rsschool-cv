03 Code Example

A short Codewars solution — “Multiples of 3 or 5” — written in JavaScript, included here as text rather than a screenshot: 

function solution(number) {
    let total = 0;

    for (let i = 1; i < number; i++) {
        if (i % 3 === 0 || i % 5 === 0) {
        total += i;
        }
    }

    return total;
    }
