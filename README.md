# rsschool-cv

My CV built for the RS School "CV. HTML, CSS & Git Basics" task.

**Live page:** https://Daurosh.github.io/rsschool-cv/

## Stack

- Semantic HTML5
- CSS (custom properties, Grid, Flexbox)
- Vanilla JavaScript
- No frameworks, no build step

## Structure

- `index.html` — CV markup
- `css/` — style modules
- `js/script.js` — interactivity
- `images/` — avatar and RS School logo
